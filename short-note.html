HEAP / PRIORITY QUEUE (L09)

PQ = ADT "สิทธิ์สูงออกก่อน" · ใช้ binary heap: min heap แม่≤ลูก (root น้อยสุด) · max heap แม่≥ลูก · heap ไม่เรียงซ้าย→ขวา!

สูตร array (node i): ลูกซ้าย 2i+1 · ลูกขวา 2i+2 · แม่ (i−1)/2 · root = index 0

  • insert d: วางท้าย (size++) → ขึ้น: while p>0 && heap[p]<heap[(p−1)/2] → swap
  • removeMin: จำ root → heap[0]=heap[−−size] → ลง: เทียบลูก เล็กกว่า (min heap) สลับจนแม่≤ลูก · 3 เคส: ไม่มีลูก break / ลูกเดียว (ซ้าย) เทียบแล้ว break / 2 ลูก เลือก min(ซ้าย,ขวา)
  • peek O(1) · insert/remove O(log n)
  • heapify (build heap จาก array) = O(n) · insert ทีละตัว n ครั้ง = O(nlogn) — ไม่เหมือนกัน!
  • Heap sort: heapify + remove วน n ครั้ง → เรียง (code: heap[size]=d ทิ้งไว้ท้าย = เรียงมาก→น้อย) O(nlogn), ไม่ stable
  • ลบ node ใด ๆ: แทนด้วยใบสุดท้าย แล้ว percolate ขึ้น/ลงตามความเหมาะ
  • PQ สิทธิ์เท่ากันไม่การันตี FIFO → แก้: เก็บ counter เข้าก่อน-ออกก่อน
  • kth ใหญ่สุด (stream) → min heap ขนาด k (root = อันดับ k) · O(log k)/ตัว

BST (L10)

ศัพท์: root / leaf (ไม่มีลูก) / siblings (แม่เดียวกัน) / depth (edge จาก root) / height (depth มากสุด) / subtree
balanced: สูง O(log n) · deformed: โน้ม O(n) = linked list

กฎ BST: ทุก node — ลูกซ้ายทั้งฝั่ง < node < ลูกขวาทั้งฝั่ง

Traversal (O(n)): Pre = Root L R · In = L Root R · Post = L R Root
In-order ของ BST = เรียงน้อย→มาก (ใช้ตรวจคำตอบ!)

insert: search หาช่องว่างแล้ววาง · ลำดับ insert เรียงมาแล้ว → ต้นเอียง

searchIter (ออกสอบ!):

TreeNode searchIter(int key){
  TreeNode cur = root;
  while (cur != null) {
    if (key == cur.data) return cur;
    else if (key < cur.data) cur = cur.left;
    else cur = cur.right;
  }
  return null;
}

AVL (L11)

height: ใบ=0, null=−1 · BF = hL − hR อนุญาต −1/0/+1 · |BF|≥2 → หมุน · สูง < 1.44 log₂n · insert/delete/search O(log n)

4 เคส (ดู 2 ก้าวท้ายของเส้นทาง):

เคสแก้
LL (ซ้าย-ซ้าย, BF+2, ลูกซ้าย BF≥0)หมุนขวา ที่ node
RR (ขวา-ขวา, BF−2, ลูกขวา BF≤0)หมุนซ้าย ที่ node
LR (ซ้ายแล้วขวา, ลูกซ้าย BF<0)หมุนซ้ายที่ลูกซ้าย → หมุนขวาที่ node
RL (ขวาแล้วซ้าย, ลูกขวา BF>0)หมุนขวาที่ลูกขวา → หมุนซ้ายที่ node

ทำ: insert แบบ BST → เดินขึ้นคิด BF ทุกชั้น → เจอ |BF|=2 หมุนที่ node นั้น (insert หมุน ≤1 ชุด; delete ไล่ขึ้นได้ทุกชั้น) → update height

หมุนซ้ายที่ n = ลูกขวาขึ้นแทน (subtree กลางย้ายไปลูกขวาของ n) · หมุนขวา = กลับกัน · ต่อ parent + update h เสมอ

RED-BLACK (L11)

กฎ 5 ข้อ: ① เป็น BST ② สีแดง/ดำ ③ root ดำ ④ แดงไม่มีลูกแดง ⑤ ทุกเส้นทาง→NIL มี จำนวนดำเท่ากัน (NIL นับดำ)

เส้นยาวสุด ≤ 2×สั้นสุด → h ≤ 2log₂(n+1) → search/insert/delete O(log n)

insert node ใหม่ = แดงเสมอ แล้ว:

  • พ่อดำ → จบ
  • พ่อแดง + ลุงแดง → recolor: พ่อ+ลุง=ดำ, ปู่=แดง → ขยับไปตรวจที่ปู่ (root แดง → ดำ)
  • พ่อแดง + ลุงดำ/NIL → หมุนที่ปู่ (LL/RR เดี่ยว, LR/RL คู่) + recolor: ตัวขึ้น=ดำ ปู่=แดง → จบ

SPLAY (L11)

ทุก access → splay ขึ้น root (หมุนโดย BST ยังถูก) · ของที่ใช้บ่อยลอยบน · ไม่เก็บ height/สี

  • Zig/Zag: พ่อ = root → หมุนที่พ่อ 1 ครั้ง
  • Zig-Zig/Zag-Zag: เลี้ยวทางเดียวกัน → หมุน ปู่ก่อน แล้วพ่อ
  • Zig-Zag/Zag-Zig: คนละทาง → หมุน พ่อก่อน แล้วปู่

delete x: ① search+ splay x ขึ้น root ② splay max ฝั่งซ้าย ขึ้นหัว subtree ซ้าย ③ root ใหม่ = ตัว max นั้น, ลูกขวา = subtree ขวาเดิม

amortized: M ops บน N node = O(M log N) → O(log N) เฉลี่ย (เดี่ยว ๆ อาจ O(n))

BFS / DFS

สถานะ: unvisited → discovered → explored · BFS = Queue (กว้างก่อน, mark ตอน enqueue) · DFS = Stack/recursive (ลึกก่อน, mark ตอนเหยียบ) · ทั้งคู่ O(V+E)

dfs(v){ if visited return; visited=true;
  for w adj v: if !visited dfs(w); }

BFS ในกราฟไม่มีน้ำหนัก → d[w]=d[u]+1 = เส้นน้อยสุด + path[] ย้อนทาง

PRIM (MST)

เริ่มจุดใดก็ได้ → วน: หยิบจุดนอกต้นไม้ที่ key น้อยสุด (key = เส้นถูกสุดพาเข้า tree) → relax: w(u,v)<key[v] → อัปเดต + parent · จบเมื่อครบ V · O(E log V) (lazy PQ)

DIJKSTRA (SSSP)

จาก s ไปทุกจุด, น้ำหนัก ≥ 0 เท่านั้น · dist[s]=0 ที่เหลือ ∞ · วน: pop (dist น้อยสุด) → relax ทุกเส้น: alt = dist[u]+w < dist[v] → dist[v]=alt, prev[v]=u, push เพิ่ม · ผล: dist[], prev[] (ย้อนทาง) · O(E log V)

push(pq,0,s)
while(!pq.empty()){
  (du,u)=extractMin(pq)
  if (du > dist[u]) continue; // stale
  for (u,v,w):
    if(du+w < dist[v]){ dist[v]=du+w;
      prev[v]=u; push(pq,dist[v],v); } }

Prim vs Dijkstra: ต่างกันที่ priority: key=เส้นถูกสุดเข้า tree ↔ dist=ระยะรวมจาก s · MST ไม่ใช่เส้นทางสั้นสุด!

UNION-FIND

find(x) = หัวกลุ่ม · union รวมกลุ่ม · ใช้กันวงใน Kruskal

find(x){ if(parent[x]!=x)
  parent[x]=find(parent[x]); // path compression
  return parent[x]; }
union(a,b){ ra=find(a); rb=find(b);
  if(ra==rb) return;      // กลุ่มเดียว = วง!
  if(rank[ra]<rank[rb]) parent[ra]=rb;
  else if(rank[ra]>rank[rb]) parent[rb]=ra;
  else { parent[rb]=ra; rank[ra]++; } }

union by rank: ต้นสั้นใต้ต้นสูง (เท่ากัน → เลือก + rank++) · path compression: รีดชี้ตรง root → find/union ≈ O(1) (α(n))

KRUSKAL (MST)

เรียงเส้น w น้อย→มาก → วน: ถ้า find(u)≠find(v) → รับ + union · ถ้าเท่ากัน → ทิ้ง (วง!) · จบเมื่อได้ V−1 เส้น · ต้นทุน = sort = O(E log E)

เขียนตาราง: เส้น | find | ตัดสิน | กลุ่มหลังรวม
