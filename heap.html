Priority Queue & Heap — คิวที่คนสำคัญเข้าก่อน

รีวิวรุ่นพี่เจอ 2 แนว: "มี tree มาให้ ถ้า insert เลขนี้ tree ใหม่จะเป็นยังไง" (Final 66) และ "Min Heap + delete min node" (Final 67) — ทั้งสองแนวใช้แค่ 2 การเคลื่อนไหว: เคาะขึ้น (percolate up) กับ เคาะลง (percolate down) ฝึกจากหน้านี้ให้คล่องแล้วจบ

🚑 Priority Queue (ADT) — คิวแบบมีสิทธิ์

📗พื้นฐาน: Queue และ ADT

Queue (คิว) ที่เราคุ้นเคยคือ FIFO — First In First Out, เข้าก่อนออกก่อน เหมือนแถวซื้อข้าว โครงสร้างเชิงตรรกะ (ADT = Abstract Data Type) คือ "สัญญาว่าทำอะไรได้บ้าง" (enqueue/dequeue) ไม่ผูกว่า "ข้างในเขียนด้วยอะไร"

Priority Queue คือ ADT แบบเดียวกัน แต่เปลี่ยนกฎการออก: ไม่ดูว่าเข้าก่อน ดูว่า "สำคัญกว่า" — สิทธิ์สูงออกก่อนเสมอ เหมือนห้องฉุกเฉินโรงพยาบาล: คนไข้หนัก (priority สูง) เข้าห้องหมอก่อน แม้จะมาถึงทีหลังเพื่อน

ตัวอย่างจากสไลด์: ฝากข้อมูล 7, 3, 5, 4, 2 ตามลำดับ โดยแต่ละตัวมี priority 2, 3, 2, 1, 1 (เลขน้อย = สำคัญกว่า):

⚠️คนสิทธิ์เท่ากัน ไม่การันตี "มาก่อน-ออกก่อน"!

Heap ปกติไม่รับประกันว่าคน priority เท่ากันจะออกตามลำดับเข้า (FIFO) — ถ้าโจทย์ต้องการ ให้แก้ด้วยการ เก็บ "ลำดับที่เข้า" (counter/timestamp) ติดไปกับข้อมูล แล้วใช้เป็นตัวตัดสินรองเมื่อ priority เท่ากัน

🌍 ใช้ทำอะไรในโลกจริง

  • OS: จัดคิว process (process scheduling), จัดการ interrupt — งานด่วนได้ CPU ก่อน
  • อัลกอริทึมกราฟ: Dijkstra (หาเส้นทางสั้นสุด), Prim (MST), Huffman coding — เดี๋ยวเจอมันอีกรอบในบท Graph!
  • ระบบทรัพยากร: load balancing, เราเตอร์เครือข่าย (packet สำคัญส่งก่อน)
  • หน้างานบริการ: คิวลูกค้า VIP, คิวตรวจภายใน

⛰️ Heap — โครงสร้างที่ใช้สร้าง PQ ที่ดีที่สุด

ทำ PQ ด้วย array หรือ linked list ตรง ๆ ก็ได้ แต่ไม่ดี (อย่างดีอย่างหนึ่งจะช้า: array เรียง → insert แพง; array ไม่เรียง → remove min ต้องไล่หา O(n)) binary heap ให้ insert/remove/peek ได้ O(log n)/O(log n)/O(1) — นิยาม:

  • Min heap: พ่อแม่ (parent) ≤ ลูกทุกคน → root คือค่าน้อยสุดของทั้ง heap เสมอ
  • Max heap: พ่อแม่ ≥ ลูกทุกคน → root คือค่ามากสุด
  • ห้ามลืม: heap เทียบแค่ "พ่อ-ลูก" ไม่ได้เรียงซ้ายก่อนขวา! (ต่างจาก BST — จุดเติมคำชวนออก)

⬆️ insert — วางท้ายแล้ว "เคาะขึ้น" (percolate up)

ขั้นตอน insert ค่า d ลง min heap: (1) วาง d ที่ช่องท้ายสุด (ตำแหน่ง size++ — ช่องนี้ว่างเสมอเพราะ complete tree) (2) เทียบกับแม่: ถ้า d < แม่ → สลับ แล้วเทียบต่อขึ้นไปเรื่อย ๆ (3) หยุดเมื่อแม่ ≤ ตัวเอง หรือขึ้นไปถึง root

💡เปรียบเทียบ

เหมือนพนักงานใหม่ตัวจิ๋วได้เข้า "ตำแหน่งสุดท้าย" ขององค์กรก่อน แล้วค่อย ๆ เลื่อนขึ้นเป็นขั้น: ถ้าเก่งกว่าหัวหน้า (ค่าน้อยกว่า) ก็สลับตำแหน่งกับหัวหน้า ไต่ขึ้นไปเรื่อย ๆ จนเจอหัวหน้าที่เก่งกว่าตัวเองก็หยุดอยู่ตรงนั้น

วาง 3 ที่ช่องท้าย (i=6, ลูกขวาของ 8)array: [2,5,8,9,7,10,3] — ยังไม่ถูกกฎ เพราะแม่ (8) ใหญ่กว่า 3

เทียบ 3 กับแม่ใหม่ (root = 2) → 3 > 2 หยุด ✅ผลลัพธ์: [2,5,3,9,7,10,8] — heap ถูกกฎแล้ว จบใน 1 ครั้งของการสลับ

โค้ด insert จากสไลด์ (อ่านทีละบรรทัดให้ครบ)

public void insert(int d) {
  int p = size++;      // เพิ่มพื้นที่ 1 ช่อง แล้วชี้ช่องท้าย (วาง d ไว้ท้ายสุด)
  heap[p] = d;
  int parent = (p-1)/2;            // สูตรหาแม่
  while ( (p > 0) && (heap[p] < heap[parent]) ) {  // min heap: ลูกน้อยกว่าแม่ → สลับ
    swap(p, parent);
    p = parent;                    // ตัวเราย้ายขึ้นไปอยู่ที่ของแม่เดิม
    parent = (p-1)/2;              // อัปเดตแม่คนใหม่
  }
}   // จบ loop อัตโนมัติเมื่อ (p==0 → ถึง root) หรือ (แม่ ≤ ตัวเอง)

ถ้าเป็น max heap เปลี่ยนเงื่อนไขเป็น heap[p] > heap[parent] — แค่นิดเดียว ระวังโจทย์ถาม min หรือ max!

⬇️ remove (delete min) — หยิบ root แล้ว "เคาะลง" (percolate down)

การลบ "น้อยสุด" = ลบ root: (1) จำค่า root เก็บไว้คืน (2) ยกใบสุดท้ายของ array ขึ้นมาแทน root (ย้ายตัวเดียว ไม่ง้อโครง) (3) ตัวใหม่อาจใหญ่เกิน → เทียบกับ ลูกตัวเล็กกว่า แล้วสลับลงไปเรื่อย ๆ จนลูกทั้งคู่ใหญ่กว่าตัวเอง หรือตกถึงใบ

⚠️เลือกลูก "ตัวเล็กกว่า" เสมอ (min heap)

ตอนเคาะลงต้องสลับกับ min(ลูกซ้าย, ลูกขวา) — ถ้าเลือกผิดฝั่ง (สลับกับลูกใหญ่กว่า) กฎ heap จะพังทันที เพราะตัวที่ถูก "ชนขึ้น" จะกลายเป็นแม่ของลูกอีกฝ่ายโดยมีค่ามากกว่า

จำ root (3) ไว้คืนค่าค่าที่จะ return = 3
ยกใบสุดท้าย (8) ขึ้น rootarray: [8, 5, 6, 9] (size ลดเหลือ 4) — ผิดกฎ เพราะ 8 ใหญ่กว่าลูก
เทียบ 8 กับลูก (5, 6) → ตัวเล็กกว่าคือ 5 → สลับarray: [5, 8, 6, 9] — 8 ตกลงไป i=1
เทียบ 8 กับลูกของมัน (9) → 8 < 9 หยุด ✅ผลลัพธ์: [5, 8, 6, 9] · return 3 — heap กลับมาถูกกฎ

✂️ ถ้าโจทย์ให้ "ลบ node อื่น" ที่ไม่ใช่ root

โจทย์ Final 67 มี "Delete Min Node ที่น้อยที่สุด" (คือลบ root) — แต่เผื่อโจทย์ให้ลบค่าอื่น เช่น ลบ 9 ที่เป็นใบ หรือลบ 6 ที่มีลูกเดียว หลักการเดียวกันทั้งหมด:

ลบใบ (leaf) — ง่ายสุดแค่ตัดออกจาก array ตัวเดียว โครง heap ไม่พังเลย (ใบไม่มีลูกให้เสียกฎ)
ลบ node ลูกเดียวแทนที่ node ด้วย "ลูกตัวนั้น" ขึ้นมา — เพราะ complete tree จะมีลูกเดียวได้เฉพาะใบสุดท้ายฝั่งซ้าย การยกลูกขึ้นจึงไม่ทำให้เกิดรูกลาง array
ลบ node สองลูก (เช่น root)ยก "ใบสุดท้ายของ array" มาแทนที่ แล้ว เคาะขึ้นหรือเคาะลงตามความเหมาะ: ถ้ามันเล็กกว่าแม่ → percolate up · ถ้าใหญ่กว่าลูก → percolate down (บางครั้งทั้งสองอย่างไม่จำเป็น)

💻 โค้ดเต็ม MyMinHeap + MyPQueue (จากสไลด์)

public class MyMinHeap {
  int MAX_SIZE = 100;
  int heap[] = new int[MAX_SIZE];
  int size = 0;

  public void insert(int d) {          // O(log n)
    int p = size++;  heap[p] = d;
    int parent = (p-1)/2;
    while (p > 0 && heap[p] < heap[parent]) { swap(p, parent); p = parent; parent = (p-1)/2; }
  }
  public int remove() {                 // O(log n) — ดึงน้อยสุด
    int d = heap[0];
    heap[0] = heap[--size];              // ใบสุดท้ายขึ้น root, ช่องท้ายว่างลง
    heap[size] = d;                      // แถวนี้จากสไลด์: เก็บค่า root ทิ้งไว้ช่องท้าย (สำหรับ heap sort!)
    int p = 0;
    while (true) {
      int left = 2*p+1;
      if (left >= size) break;           // เคส 1: ไม่มีลูก
      int right = 2*p+2;
      if (right == size) {               // เคส 2: ลูกเดียว
        if (heap[p] > heap[left]) swap(p, left);
        break;
      }
      int q = heap[left] < heap[right] ? left : right;  // เคส 3: เลือกลูกเล็กกว่า
      if (heap[p] > heap[q]) { swap(p, q); p = q; }
      else break;
    }
    return d;
  }
  public int peek() { return heap[0]; }        // O(1) มองน้อยสุดโดยไม่ดึงออก
  public boolean isFull() { return size == MAX_SIZE; }
  public boolean isEmpty() { return size == 0; }
}

public class MyPQueue {          // PQ = ห่อ heap ไว้อีกชั้น
  MyMinHeap heap = new MyMinHeap();
  public void enqueue(int d) { heap.insert(d); }   // ADT ใช้ชื่อ queue แต่ข้างในเป็น heap
  public int dequeue()      { return heap.remove(); }
  public int front()        { return heap.peek(); }
}

สังเกตบรรทัด heap[size] = d; — สไลด์ "ทิ้ง" ค่าเก่าไว้ช่องท้ายโดยตั้งใจ ถ้าเรียก remove วนซ้ำจนหมด ข้อมูลทั้ง array จะเรียงจากมากไปน้อยพอดี → นั่นแหละ heap sort ซ่อนอยู่ใน remove!

🏗️ Heapify — สร้าง heap จาก array เดิม ใน O(n) เท่านั้น!

สองวิธีสร้าง heap จาก n ตัว:

  • insert ทีละตัว n ครั้ง: แต่ละครั้ง O(log n) → รวม O(n log n)
  • heapify: ถือว่า array ที่มีอยู่เป็น tree ไปเลย แล้ว "เคาะลง" จาก node กลาง ๆ ((n-2)/2) ย้อนกลับมาถึง root → O(n)! เพราะ node ส่วนใหญ่ใน tree อยู่ "ลึก ๆ ใกล้ใบ" (ครึ่งหนึ่งของ node เป็นใบ) — ใบไม่ต้องทำอะไรเลย ตัวที่ต้องเดินไกลมีแค่นิดเดียว เฉลี่ยต่อ node จึงคงที่

สรุปข้อสอบ: build heap จาก array ด้วย heapify = O(n) · insert สะสม n ตัว = O(n log n) — สองค่านี้ไม่เหมือนกัน โจทย์ชอบวัด!

Heap Sort — ดึง root ทีละตัวจนหมด = ได้ข้อมูลเรียงฟรี ๆ

  1. heapify array ทั้งก้อน (O(n))
  2. เรียก remove วน n ครั้ง (ครั้งละ O(log n)) — ทุกครั้ง root (น้อยสุด) ถูกวางไว้ท้าย array ตามโค้ดข้างบน → array กลายเป็นเรียง มาก→น้อย (ถ้าอยากได้น้อย→มาก ใช้ max heap)

สรรพคุณ: Best = Average = Worst = O(n log n) · Stable No · (สไลด์ใส่ memory O(n) เพราะใช้ array เดิมเป็นที่เก็บผล — ตัวเรียงตัวเอง in-place O(1) เพิ่มเติม)

🏅 Challenge ท้ายบท: หาคะแนนอันดับ k สูงสุดจากสตรีม

📝โจทย์จากสไลด์ (Example Challenge)

เขียน class ที่รับคะแนนไหลเข้ามาเรื่อย ๆ (stream) และทุกครั้งที่มีคะแนนใหม่ ต้องตอบ "คะแนนอันดับ k สูงสุด" ได้ทันที

เฉลยแนวคิด — ใช้ min heap ขนาด k (ตัวเล็กสุดของกองคือ "อันดับ k")

ไอเดีย: เก็บ "หนึ่งวงของ k ตัวที่ใหญ่ที่สุดเท่าที่เคยเห็น" ไว้ใน min heap — root ของ min heap คือตัวเล็กสุดในวง = อันดับ k พอดี:

  1. ใส่คะแนนใหม่ลง heap
  2. ถ้าขนาด heap > k → ทิ้ง root (ตัวเล็กสุด) ออก
  3. ตอบ = root (ถ้า heap ยังไม่เต็ม k ตัว ตอบตัวเล็กสุดที่มีอยู่ก่อน)

ตัวอย่าง k = 3 กับคะแนน 60, 85, 70, 90, 75:

คะแนนเข้าheap หลังจัดตอบ (อันดับ 3)
60{60}—
85{60, 85}—
70{60, 70, 85}60
90{70, 85, 90} (ทิ้ง 60)70
