✏️ Drill 1: trace Sorting 3 แบบ (ออกทุกปี)

📝โจทย์: ข้อมูล [5, 1, 4, 2, 8] — แสดงขั้นตอนละเอียดพร้อมผลลัพธ์สุดท้าย ของ (ก) Bubble (ข) Selection (ค) Insertion (ง) Quick

เคล็ด: เขียน array ใหม่ทุกครั้งที่สลับ/วาง + ระบุรอบ — อย่าลืม "รอบสุดท้ายที่ไม่มีการสลับ" ของ improved bubble

เฉลย (ก) Bubble Sort

Pass 1: (5,1)สลับ → [1,5,4,2,8] · (5,4)สลับ → [1,4,5,2,8] · (5,2)สลับ → [1,4,2,5,8] · (5,8)ไม่สลับ → จบ pass: [1,4,2,5,8] (8 ล็อกท้าย)

Pass 2: (1,4)ไม่สลับ · (4,2)สลับ → [1,2,4,5,8] · (4,5)ไม่สลับ → [1,2,4,5,8]

Pass 3: (1,2)ไม่สลับ · (2,4)ไม่สลับ → ไม่มีการสลับเลย → เรียงเสร็จ หยุด (improved) ✅

ผลลัพธ์สุดท้าย: [1, 2, 4, 5, 8] — รวม 7 เทียบ 5 สลับ

เฉลย (ข) Selection Sort

รอบ 1: min ของทั้งแถว = 1 (index 1) → สลับกับ index 0 → [1, 5, 4, 2, 8]

รอบ 2: min ของ {5,4,2,8} = 2 → สลับกับ index 1 → [1, 2, 4, 5, 8]

รอบ 3: min ของ {4,5,8} = 4 → อยู่ที่ถูกแล้ว ไม่สลับ · รอบ 4: min {5,8} = 5 อยู่แล้ว

ผลลัพธ์สุดท้าย: [1, 2, 4, 5, 8] — เทียบ 10 ครั้ง (ตายตัว) สลับแค่ 2 ครั้ง

เฉลย (ค) Insertion Sort

หยิบ 1: 5 > 1 เลื่อน 5 → [1, 5, 4, 2, 8] · หยิบ 4: เลื่อน 5 → [1, 4, 5, 2, 8]

หยิบ 2: เลื่อน 5, 4 → [1, 2, 4, 5, 8] · หยิบ 8: ใหญ่สุดแล้ว ไม่เลื่อน

ผลลัพธ์สุดท้าย: [1, 2, 4, 5, 8] — จำนวน "เลื่อน" = จำนวน inversions = 4 (คู่ 5-1, 5-4, 5-2, 4-2)

เฉลย (ง) Quick Sort (pivot = ตัวท้ายเสมอ)

รอบแรก: [5, 1, 4, 2, 8] pivot = 8 → ทุกตัว ≤ 8 → pivot อยู่ที่เดิม index 4 → ซ้าย {5,1,4,2}, ขวาว่าง

quicksort [5,1,4,2]: pivot = 2 → เจอ 1 ≤ 2 สลับมาหน้า → [1, 5, 4, 2] → จบ partition สลับ pivot เข้าที่ index 1 → [1, 2, 4, 5] → ซ้าย {1} ขวา {4,5}

quicksort [4,5]: pivot = 5 → 4 ≤ 5 → pivot คงที่ → เรียงแล้ว

ผลลัพธ์สุดท้าย: [1, 2, 4, 5, 8] — สังเกตว่า pivot 8 แย่สุด ๆ (ข้อมูลเกือบเรียง) = โจทย์จงใจให้เห็น worst-ish case แต่ก็ยังเรียงได้

✏️ Drill 3: สร้าง BST + เติม searchIter (Final 66/67)

📝โจทย์ (ก): แสดงขั้นตอนสร้าง BST จาก 50, 30, 70, 20, 40, 60, 80 (ข): เติมโค้ดบรรทัดที่หายของ searchIter
เฉลย (ก)
  1. 50 → root
  2. 30 < 50 → ซ้ายของ 50
  3. 70 > 50 → ขวาของ 50
  4. 20 < 50, < 30 → ซ้ายของ 30
  5. 40 < 50, > 30 → ขวาของ 30
  6. 60 > 50, < 70 → ซ้ายของ 70
  7. 80 > 50, > 70 → ขวาของ 70

ผลลัพธ์: 50(30(20, 40), 70(60, 80)) — ต้นสมมาตรพอดี · ตรวจ in-order: 20,30,40,50,60,70,80 เรียง ✅

เฉลย (ข) searchIter — โครงคือ "เดินตามกฎจน null"
TreeNode searchIter(int key) {
  TreeNode cur = root;
  while (cur != null) {
    if (key == cur.data) return cur;          // ← บรรทัดที่มักให้เติม
    else if (key < cur.data) cur = cur.left;  // ← หรือบรรทัดนี้
    else cur = cur.right;                     // ← หรือบรรทัดนี้
  }
  return null;
}

จำหลัก: เท่ากัน return · น้อยกว่าไปซ้าย · มากกว่าไปขวา · หลุดใบคืน null

✏️ Drill 9: เขียนโปรแกรม Binary String (โค้ดข้อเดียวของปี 67)

📝โจทย์: เขียนโปรแกรมรับค่า K ใด ๆ แล้วแสดง binary string ความยาว K ทั้งหมด โดยเงื่อนไข "1 ห้ามติดกัน"

เช่น K = 3 → ต้องได้ 000, 001, 010, 100, 101 (ส่วน 011, 110, 111 มี 1 ติดกัน → ตัด)

แนวคิด: สร้างเป็น "ต้นไม้การตัดสินใจ" (recursion)

สร้าง string ทีละตำแหน่งจากซ้ายไปขวา — ทุกตำแหน่งเลือกได้ 2 ทาง (0 หรือ 1) ยกเว้น: ถ้าตัวก่อนหน้าเป็น 1 → ตำแหน่งนี้เลือกได้แค่ 0 ลองวาดเป็นต้นไม้ K = 3 (เริ่มก่อนตัวแรกด้วย "ไม่มี 1" จึงวาง 0 หรือ 1 ได้อิสระ):

public class BinaryString {
  static void gen(String s, int k, char last) {
    if (s.length() == k) {                    // ครบ K ตัว = ถึงใบ → พิมพ์
      System.out.println(s);
      return;
    }
    gen(s + "0", k, '0');                     // ทางเลือก 1: วาง 0 ได้เสมอ
    if (last != '1')                          // ทางเลือก 2: วาง 1 ได้เฉพาะเมื่อตัวก่อนไม่ใช่ 1
      gen(s + "1", k, '1');
  }
  public static void main(String[] args) {
    int k = 3;                                // รับค่า K ใด ๆ
    gen("", k, '0');                          // เริ่มด้วย last='0' → ตัวแรกวาง 1 ได้อิสระ
  }
}
// K=3 → 000, 001, 010, 100, 101 (5 แบบ)

จำนวน string ทั้งหมด = เลขฟีโบนัชชี! K=1→2, K=2→3, K=3→5, K=4→8 (จำนวนที่ยาว n ไม่มี 1 ติดกัน = จำนวน(ยาว n−1) + จำนวน(ยาว n−2)) — เหตุผล: string ยาว n จบด้วย 0 → หน้าเป็นอะไรก็ได้ของ n−1 · จบด้วย 1 → หน้าต้องจบ 0 ของ n−2
